# deep-video-engine · 原创深度视频引擎

把知识型频道的叙事方法转化为原创视频生产流程：**频道结构拆解 → 原创选题 → 独立研究 → 旁白 → 分镜 → Google Flow 批次提示词 → 剪辑交接**。

平台、语言、时长和画幅每次调用时指定。可以只完成某个阶段，也可以读取项目状态继续生产。

## 安装

```bash
npx -y skills add benxuCHN/deep-video-engine -g --all
```

## 从主题开始

```text
使用 $deep-video-engine。
主题：为什么城市会建地下蓄水设施？
受众：对城市基础设施感兴趣的普通观众。
平台：YouTube；语言：中文；目标时长：8分钟；画幅：16:9。
完成事实研究、原创旁白、分镜和Flow批次提示词。
参考视频：[填入可访问链接或附上材料，也可以不提供]。
先做到前期生产包，不提交付费生成。
```

## 只拆解参考频道

```text
使用 $deep-video-engine，分析这些参考视频：[链接或字幕文件]。
先提炼开场承诺、解释层次、过渡和收尾，再给5个原创选题与搜索词。
这次不写稿。
```

只有字幕时分析文字叙事；判断运镜、画面与视觉比例需要实际视频或帧图。没有表现数据时不会把“最新视频”自动称为“爆款”。

## 已有稿件或继续项目

```text
使用 $deep-video-engine，把附上的定稿拆成独立镜头。
语言：中文；画幅：16:9；目标时长：6分钟。
交付视觉设定、逐镜表和可粘贴的Flow批次提示词。
```

```text
使用 $deep-video-engine，继续项目：[项目目录]。

```

## 交付物

按实际完成阶段输出，不要求每次生成所有文件：

| 阶段 | 主要交付 |
| --- | --- |
| 拆解与选题 | 结构证据表、原创候选、具体搜索词 |
| 事实研究 | 来源记录、断言账本、缺口与争议 |
| 旁白 | 审阅稿、来源映射、纯旁白、时长估算 |
| 视觉规划 | 共享视觉规则、完整逐镜表、独立批次提示词 |
| 交接与续作 | 编辑图层说明、剪辑交接、项目状态与真实素材记录 |

## 工作原则

- 参考材料用于提炼表达方法，具体事实由独立研究资料支撑。
- 不迁移某条参考视频的措辞、独特比喻或案例排列。
- 每镜默认独立生成，区分整体剖面与局部内部展示。
- 重要文字、数字、精确地图与图表由可核验的后期图层制作。
- 按旁白长度估时，以实际配音校准；生成片长和剪辑使用时长分开。
- 只写好提示词时状态为待提交，不宣称视频已生成。

## 环境与能力边界

需要支持 Agent Skills 的客户端。研究工作需要可用的搜索／浏览工具，或用户提供的事实资料。Skill 为 Markdown 指令包，无须额外 Python 依赖。

Notebook、Flow、配音和剪辑的软件操作取决于实际连接、账号权限、额度和工具能力。本仓库不提供这些服务的凭证或私有 API；未连接时交付可人工粘贴的生产材料。付费生成和发布不由安装自动授权。

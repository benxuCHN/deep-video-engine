# 研究与脚本规则

## 事实账本

为每个事实来源记录：F ID、标题、作者／机构、URL 或文件定位、发布／更新日期、访问日期、已读段落、适用范围。不能取得日期就写未知，不能猜测。

断言表列：Claim ID、拟写断言、支持它的 F ID 与段落、支持强度、时间口径、反证或争议、处理决定。对于数字补单位、统计年份、分母与地域；对于因果区分机制证据和相关性；对于历史重建区分史料和合理推测。

只有结构参考时可做拆解、选题和研究计划；不能凭参考故事补出新主题事实。用户禁止联网时使用给定事实材料，缺失项明示，不虚构来源。来源数量不是可靠性的替代指标；围绕一个断言集中证据。

## 原创推进

按新主题证据重组：可观察的反常现象 → 解释目标 → 初步解释及其不足 → 更深层机制／约束 → 后果 → 回答开场问题。可改变顺序，避免将所有题目套成侦探故事。

逐段指定解释任务、需要的断言、观众当前已知和下一问。悬念是证据尚未揭示，不是故意省去会改变结论的限定。

定稿交付两个版本：
1. 带 P ID 的审阅稿及段落—断言映射。
2. 连续的纯旁白稿，供 TTS／配音使用。

制作备注、引用、发音说明、画面指令另存。标题与开场不能比已支持的结论更强。不得将“尚不明确”改写成“惊天秘密”。

## 时长

记录字数／词数、语速、预计时长和计算口径。中文只统计口播文字，不含段号、标点和来源表；英文按口播词数计。混合语言分别估算。语速仅为初稿假设。

先按段落估时拆镜；收到最终音频后，以真实音轨和逐段对齐更新分镜。没有实际音频不得将估时作为帧级准确时间码。为长解释可增加图解镜头，不靠无意义慢放填满。

## 原创性检查

对比参考材料的措辞、独特比喻、案例组合和事件排序。记录能够观察到的借鉴关系及改动。没有全网比对不声称“查重 100%”；无需为了与参考相异而扭曲事实。

# 视觉选择与分镜规则

## 按解释问题选类型

| 要解释的问题 | 视觉方式 | 取景决定 |
| --- | --- | --- |
| 事物规模、现实环境、基础设施 | 环境／纪实风格场景 | 主体与尺度关系清楚，运动克制 |
| 在哪里、通向哪里、地形如何约束 | 地理图解 | 准确位置和边界由地图数据制作，生成画面只作示意 |
| 隐藏系统整体如何布置 | C1 整体剖面 | 仅当空间关系本身是信息时展示全体 |
| 某个局部空间里发生什么 | C2 局部剖面 | 靠近暴露的内部，外围裁掉，避免远景模型台座 |
| 部件如何作用、压力／水流如何传递 | 机制图解 | 用可读的部件关系和运动方向解释，避免无关环境 |
| 对比、比例、时间顺序或因果链 | 信息图 | 精确数据用程序图表或编辑器形状实现 |

C2 是需要呈现局部内部时的优先选项，不是所有主题的默认镜头。无隐藏结构的题目不硬塞剖面。原提示词的比例仅是一个基础设施选题示例；实际配比根据解释任务计算并说明。

## 逐镜表

必需列：镜号、旁白段号、原文片段、估计起止／时长、解释目的、视觉类型、取景、生成方式、完整生成提示词、编辑图层、事实／素材来源、状态。

先按每镜口播字数、语速和停顿分配时长，不能用总时长除以镜头数直接均分。剪辑使用时长和生成服务可选片长分别记录；工具不支持目标长度时生成较长素材后裁切，或调整镜头设计，不假称支持任意秒数。

每个旁白字符／词按顺序进入分镜；不要只截开头一句代表整个段落。多个镜头分担长句时划定各自片段。无旁白的呼吸镜标为空镜，不虚构口播。多句可在一个镜头停留，但应能在计划时长内说完。

## 独立提示词组成

使用所选生成工具可理解的语言；无指定时可用英文生成提示词、用户语言作说明。提示词包含主体、必要背景、视觉类别、取景距离、画幅、材质照明、一个核心运动及收束状态。

每镜重述完整风格，不用“同上”或“继续上一镜”。不需要参考角色身份和接帧。避免让一条短视频完成多个互不兼容的动作。

C2 镜头明确局部内部占据主体、近距离视点、外围裁切及无台座；但不伪称真实结构精准重建。无法验证的内部采用简化示意，不生成虚构的精密管线并作为事实展示。

负面约束只放相关项，例如地图镜不生成标签；不用巨长通用禁词降低主体清晰度。

## 批次

一个批次文本按镜号分块，每块包含独立提示词、所需画幅／时长和待后期添加的图层。编辑图层与生成输入隔开，避免模型画入重要数字。

Flow Agent 实际可用时才提交。先检查用户当前界面支持的模式、时长、输出数量和额度。若只支持逐条生成，保留同一分镜与镜号逐镜执行；不能把“多变体”自动等同“任意多场景并行”。

## 样片与剪辑检查

样片覆盖本项目风险最高的视觉类型。检查主体可读性、机制方向、C1／C2取景、事实误导、无关标牌和风格一致性。先修复提示词的共同问题，再扩批。

最终剪辑以已锁定旁白为时间基准。记录配音文件、实际时长、音乐许可／署名、图层文字和素材路径。检查视频开头与承诺对应、结尾回答问题、音量不遮盖旁白、画幅与字幕安全区适合目标平台。计划交付不宣称这些检查已在成片上通过。
